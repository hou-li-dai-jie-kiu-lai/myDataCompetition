# 踩坑与经验（可公开分享）

## 1. 验证必须按井

点级随机 KFold 会严重泄漏地质连续性。一律 **GroupKFold by well**。报告时同时给：

- 全局 RMSE
- 分井 RMSE / 灾难井列表

## 2. 公榜 ≠ 私榜

我们公榜最好是 **P20H (7.815)**，私榜最好是 **P88 (8.836)**。  
P20H 私榜掉到 ~9.04。选提交时若只盯公榜，最终名次会吃亏。

## 3. 离线「更强」可以是假信号

**P104**（P69 → prefix-gate → Stage3）离线投影 ~8.39，公榜 **9.54**。  
核查发现交片相对 P69 只差约 3 ft RMSE，但是：

- 两口测试井被 gate 做了近乎常数水平 snap（如 +5）
- 该偏移与原误差 **同向**，RMSE² 交叉项把分数打爆

机制：prefix-score 优化的是「侧钻预测反推回可见前缀是否顺」，**不是**侧钻真 TVT。  
**前缀最优 ≠ 真值最优**；测试井少时极易反向。

## 4. 禁止同井接触拷贝

同编号井 train 解释直接覆写 test：公榜可能虚高，私榜/规则层面不可接受。本分享方案明确不使用。

## 5. 后处理便宜且稳

Warm-up + U=TVT+Z 投影对多条 DNA 都有稳定小增益；优先于花哨井级 bias 学习。

## 6. 融合要克制

成品提交互相加权容易「离线赚、公榜亏」。P88 的融合发生在 **同协议 OOF 通道 + 折内定权**，并保留可解释的 P69 锚。

## 7. 工程建议

- 特征与模型分目录缓存；杀线实验及时删，否则磁盘爆炸  
- Notebook 提交断网：依赖提前打成 Dataset  
- 分享仓库：**代码与经验进 GitHub；权重与原始数据不要进公开库**
